TWO WAYS TO USE IT

Local generation in the app, MCP when you want it.

  • 01
    One-click local AI

    Ollama runs inside the MealPilot app stack and generates plans on your own hardware.

  • 02
    No API key

    Local generation does not call a paid model API. Ollama cloud features are disabled.

  • 03
    Structured plans

    Calories, ingredient quantities, prep time, cook time, and instructions are validated before saving.

  • 04
    Combined groceries

    MealPilot merges repeated ingredients across the whole plan.

  • 05
    MCP stays built in

    ChatGPT and other compatible clients can still read or manage MealPilot through Streamable HTTP MCP.

AI WORKFLOW

What the client should do

  1. Call get_mealpilot_context.
  2. Generate the meal plan itself using the returned preferences and pantry.
  3. Call save_meal_plan with the structured result.
  4. Later, use get_meal_plan and replace_meal for targeted changes.
No OpenAI key lives here.

MealPilot v0.3 uses local Ollama for in-app generation and still stores no OpenAI API key.
